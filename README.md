# Student-Savings-Account-System

Purpose
•The student savings account system is a simple C++ program to help students manage their savings by creating an account, deposite money, withdrawing money, and check the current balance.

Programming Language
•C++

Features
1.Create Account - The user can create a student savings account using their name.
2.Deposit Money - The user can add money to the account.
3.Withdraw Money - The user can withdraw money if there is enough balance in the account. 
4.Check Balance - The user can see how much money is in their account.
5.Exit Program - The user closes the program.

How to use the System
•The user can create a student savings account by entering their name. They can deposit money, withdraw money if they have enough balance, and check how much money is in their account. The user can also exit the program when they are done.

Errors Handling
•The Student Savings Account System checks the user's input to avoid errors. If the user enters a negative amount when depositing or withdrawing money, the program shows an invalid amount message. If the user tries to withdraw more money than their balance, the program shows an insufficient balance message. If the user enters a wrong menu choice, the program shows an error message and asks the user to enter a correct choice.

This helps the program avoid errors and keeps the account balance correct.
